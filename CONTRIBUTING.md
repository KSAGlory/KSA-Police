# Contributing

Thanks for helping improve KSA Police.

1. Open an issue describing the behavior, MTA version, Slothbot version, reproduction steps, and relevant server log excerpts. Remove account details, IP addresses, passwords, and tokens before posting.
2. Keep changes focused and compatible with a clean Freeroam server. Avoid bundling or copying code, models, textures, or audio from GTA: San Andreas or third-party resources without permission.
3. Test wanted levels 0–6, death, disconnect, resource restart, and cleanup on a separate test server. Describe what was tested and what was not.
4. Submit a pull request with a clear explanation and any required installation changes.

Feature ideas are welcome, but please distinguish a proven implementation from a proposed one. See [docs/manual-testing.md](docs/manual-testing.md).
