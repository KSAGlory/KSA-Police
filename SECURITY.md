# Security Policy

KSA Police is a small MTA server resource and is currently an experimental foundation. There is no production support guarantee.

Please report exploitable vulnerabilities through [GitHub private vulnerability reporting](https://github.com/KSAGlory/KSA-Police/security/advisories/new) rather than a public issue. Include reproduction steps, the affected version, and the likely impact. Do not include server secrets, player account data, or private host details.
